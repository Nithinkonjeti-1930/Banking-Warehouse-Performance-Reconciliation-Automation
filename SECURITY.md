# Security and data handling

This is a public portfolio repository. It must contain **only synthetic/demo data**.

Do not commit:
- employer or client source code;
- PHI, PII, account identifiers, credentials, or secrets;
- cloud service-account JSON files;
- `.env` files, private keys, logs, local databases, or production extracts.

If a secret is accidentally committed, revoke/rotate it first, then remove it from Git history.
